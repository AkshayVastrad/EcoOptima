# EcoOptima

IoT energy management for German SMEs.

EcoOptima is a concept for plug-and-play IoT energy monitoring and AI-driven optimization. Sensors collect real-time energy data, an AI cloud platform finds waste, and controlled automation adjusts HVAC, lighting and devices.

**Status:** concept stage. Savings figures are market estimates, not measured results.

## Planned architecture
Field devices (meters, smart plugs, sensors) → edge gateway (MQTT, local rules, fail-safe control) → cloud platform (time series storage, forecasting, anomaly detection, savings verification) → applications (dashboard, alerts, reports, billing).
